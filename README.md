# 🪔 Diwali Sales Analysis

An exploratory data analysis (EDA) project on Diwali sales data to uncover customer buying patterns based on **gender, age group, state, occupation, and product category**.

---

## 📌 Overview

This project analyzes a dataset of ~11,000+ transactions during the Diwali festive season. The goal is to identify **who buys what, from where, and how much** — helping businesses make data-driven marketing decisions.

---

## 🎯 Objectives

- Identify the **primary customer segments** (gender + age group)
- Discover **top-performing states** by sales amount
- Find the **most popular product categories**
- Visualize trends using clean, readable bar charts
